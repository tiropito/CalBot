# CalBot — личный веб-органайзер

Full-stack веб-приложение на **ASP.NET Core + Blazor Server** для планирования учёбы, задач и учёта рабочих смен. Данные хранятся в **PostgreSQL**.

## Возможности
- **Календарь** с автоподсчётом чётности учебных недель, интеграцией расписания и задач.
- **Задачи** с временными интервалами (включая переход через полночь), спецзадачами и быстрым редактированием.
- **Расписание** — шаблон пар на 2 недели с ФИО преподавателей и выгрузкой в CSV.
- **Модуль «Работа»** — учёт смен с расчётом часов, налогов (НПД 6%), распределением 80/20 и дашбордом.
- **Авторизация** — многопользовательский режим (BCrypt + Cookie Auth), регистрация и смена пароля.
- **Экспорт** — выгрузка задач и расписания в CSV (UTF-8 с BOM, разделитель `;`).

## Стек
- .NET 8, ASP.NET Core, Blazor Server, Razor Pages
- Entity Framework Core 8 + Npgsql
- PostgreSQL 16 (Docker Compose)
- xUnit (тесты на логику чётности недель)
